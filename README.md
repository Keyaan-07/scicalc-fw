# Scicalc firmware!

I wrote custom C firmware for my and Ahad's project for Hackclub Third SPace, and this is the repo for it!  

It uses the pico sdk to scan for the custom matrix and then apply each function/calculation accordingly. it may have bugs so reach out to me @Keyaan on hackclub slack!

Some features include:
- String Parser
- Matrix Multiplier
- PWM-dimmable brightness
- proper trigonometric functions!

This can definetely be written in a much simple manner, but hey, i am still new to C so it's okay!
